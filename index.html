Kakapo: NL2SQL Corpus Query Engine NL2SQL Product
An AI-engineered product built end-to-end and shipped to production, not a research demo: at its core is a self-hosted NL2SQL engine that lets non-technical users query and annotate large text corpora (German Bundestag speeches, climate-change discourse) in plain English. Argument-Aware Fact Checking Research Module
A fact-checking system that weighs argumentative evidence, not just keyword overlap, to judge how true a claim is, then distills that reasoning into a small model that can run entirely offline, with no dependence on large cloud models at inference time.
Beats a flat-RAG baseline by +0.26 macro-F1 (0.388 vs 0.127) on the LIAR-Arg benchmark, within 0.017 of an oracle upper bound, and edges out a published supervised baseline. The distilled 1.5B local model retains 85% of a 120B-parameter teacher's accuracy. Fully reproducible: fixed seeds, published model checkpoints on Hugging Face.

Turix: AI Execution Authority Layer Python Library
A safety control layer that sits between an AI agent's decisions and the real world: before an agent can take an action (a payment, an access grant, an infrastructure change), Turix checks it against policy and either allows, denies, or escalates it to a human, with a full audit trail.
Fail-closed by design (denies by default if unreachable), tenant-scoped, idempotent retries, versioned and hashed policies for auditability. Original systems-design work on AI agent safety, not a course assignment.

Internal Documentation RAG Assistant RAG Tool
A retrieval-augmented QA system for internal engineering docs, engineered to prioritize correctness over creativity: every answer is grounded strictly in retrieved Markdown content, with an explicit refusal when the docs don't contain the answer and full source attribution on every response, designed to never quietly hallucinate.
Fully local and reproducible, no paid APIs: FAISS semantic search over chunked docs, FLAN-T5 grounded generation with deterministic decoding, source-cited answers surfaced through a Streamlit UI showing the answer, its sources, and the retrieved debug context.

Commit-Message Bug Localization SE Research
A practical bug-localization system for large Python codebases (demonstrated on pandas, ~11,000 commits): given just a commit message describing a bug, it predicts and ranks the source files most likely responsible. A strong, interpretable ML baseline does the heavy lifting; an LLM reranker adds semantic reasoning on top through an explicit LangGraph agent pipeline, built as a post-commit sanity checker and code-review aid, not a replacement for debugging.
TF-IDF + Logistic Regression baseline alone reaches Precision@1 0.5468, Precision@3 0.7682, Precision@5 0.8635. A Groq/LLaMA reranker then adds semantic reasoning over the ML model's top-5 candidates via a 3-node LangGraph state machine (ml_candidates → shuffle_candidates → llm_rerank), with candidate shuffling built in specifically to remove positional bias.
scikit-learn (TF-IDF)LangGraphGroq (LLaMA-4 Scout)

Construct-Conditioned NL2SQL Evaluation Research
A study measuring exactly which kinds of SQL queries (joins, subqueries, negation, aggregation...) large language models get wrong when translating plain English into SQL, and testing whether smarter, construct-aware retry prompting can fix it.
Improved accuracy from 72.2% → 75.4% on the Spider benchmark via construct-aware retries, with up to +15pp gains on the hardest query types (self-joins). A controlled ablation confirmed the gain came from the retry mechanism itself, not just better prompt wording.

Dialogue-Game LLM Evaluation Multilingual Eval
An interactive evaluation framework, built on ClemBench, that tests chat LLMs with a cooperative sentence-building game instead of a static benchmark: a rule-enforcing GameMaster referees a Helper and a Seeker through constrained turns, surfacing failure modes (rule violations, over-generation, thematic drift) that single-turn benchmarks miss entirely. Run in both English and Urdu (low-resource) against a human baseline.
GPT-3.5/GPT-4 and open models (LLaMA, Gemma) evaluated against human players across easy/hard noun-pair difficulty tiers. Larger models showed more stable constraint adherence, but every model degraded significantly in Urdu, while human players kept perfect rule adherence and higher creativity: a concrete, measured multilingual generalization gap.
